## Improvement: two confirmed command-line access routes

**Status:** Both launch methods were supplied by the user and are documented as access options. This is an access/workflow improvement, not a confirmed repair to the underlying gateway or dashboard startup delay.

### 1. Hermes CLI Desktop shortcut

The user found a Windows desktop shortcut whose Target is:

```cmd
C:\Windows\System32\cmd.exe /k "hermes chat --cli"
```

This launches Command Prompt and runs the Hermes interactive CLI chat. The `/k` switch keeps the Command Prompt window open after the command is started.

### 2. Dashboard launched directly from Command Prompt

The user confirmed that they can open Command Prompt and run:

```cmd
hermes dashboard
```

This launches the Hermes web dashboard using the current Hermes installation/profile context. The user's recent dashboard launch selected the `jhermes` profile; profile selection should be checked if the user has multiple profiles.

### 3. Practical fallback sequence

1. If the normal desktop route is unavailable, use the **Hermes CLI Desktop** shortcut.
2. To access the browser dashboard, open Command Prompt and run `hermes dashboard`.
3. Allow the dashboard time to initialise; the previous launch was reported to take approximately 5–10 minutes, although the exact duration has not yet been measured.
4. If either route appears stuck, capture the exact command, timestamp and output before terminating the process or changing gateway settings.
5. Check gateway health separately with `hermes gateway status` when diagnosing a genuine gateway issue.

### 4. Important distinction

These are alternative ways to access Hermes. They do not by themselves prove that the shared gateway is healthy, fix a slow dashboard initialisation, repair session pruning, or resolve the earlier Windows startup issue. The CLI and dashboard are interfaces to the existing Hermes installation; do not reinstall or alter the gateway just because one interface is slow to open.

### 5. Verification status

- **Verified by user report:** `hermes dashboard` entered directly in CMD.
