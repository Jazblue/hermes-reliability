# Manual daily logs

Create one file per day named `YYYY-MM-DD.md`. Keep notes factual and concise. Redact credentials, account identifiers, private hostnames and sensitive data.

## Template

```markdown
# Operations log — YYYY-MM-DD

## Summary
- Overall status:

## Incidents
- Time/timezone:
- Component/job:
- Evidence (exact command/error):
- Action taken:
- Verification:
- Status: VERIFIED / OBSERVED / SUSPECTED / UNRESOLVED

## Follow-up
- [ ] Task — next check
```

Do not record a proposed action as completed. Add a verification step for every claimed fix.
